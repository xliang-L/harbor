# Harbor 路线图

Harbor 以可验证的本地营销闭环为目标：每天知道要处理什么，完成有依据的内容审批和交付，并从可靠的观察值开始下一轮工作。

本页描述当前源码范围，不承诺外部平台的服务状态或未来发布日期。

## 当前版本：0.3.0

- 今日工作台：起步清单、待审、异常、到期跟进、近期排期和效果质量入口。
- 导航与编辑：可分享的页面位置、主要表单未保存保护、保存失败保留输入和内容跨窗口版本检查。
- 品牌与商品：品牌规范、商品文件导入、素材使用权登记、独立品牌数据库。
- 来源与事实：公开来源只读采集、快照变化、商品范围事实、有效期、潜在属性冲突、撤回影响和追加式续期。
- 内容与交付：版本化文案、固定模板视频、服务端审批、渠道交付包、人工回执、防重和撤销审计。
- 指标与复盘：明确半开统计窗口、同窗同值去重、重叠/数值冲突阻断、历史问题排除和撤销重录。
- B2B 与零售：联系人/线索/跟进、未发送拓展稿、库存及销售退款导入、促销审批与人工核销。
- 可选适配器：模型、GA4 只读报表、Postiz 只读状态；Shopify / HubSpot 为本地文件导入。

相关行为由 `tests/` 中的领域、接口与浏览器回归覆盖。当前自动 CI 检查格式、lint、类型、后端测试和构建；浏览器与视频回归另需本机 Chrome 及渲染环境。

## 近期重点

| 优先级 | 工作                | 可验收结果                                                   |
| ------ | ------------------- | ------------------------------------------------------------ |
| 高     | 商品更新与历史      | 区分新增和更新，保留来源与历史，明确展示对事实和内容的影响。 |
| 高     | 品牌/规范跨窗口冲突 | 检测旧基线，保留未保存输入，避免覆盖其他窗口的新修改。       |
| 高     | 一致备份与恢复演练  | 在副本恢复数据、素材及审批历史后，仍可完成主流程。           |
| 中     | 数据新鲜度与归档    | 显示报表/来源的新鲜度，测量数据增长边界，提供可操作的归档。  |
| 中     | 创意质量与素材体验  | 用固定样本评估引用支撑和可执行性，改善搜索、预览及视频模板。 |
| 按需求 | 真实只读平台验收    | 针对具体账号验证权限、同步、防重、过期授权和错误恢复。       |

## 当前限制

统计窗口基于登记的内容版本、链接及活动/渠道口径；不能跨不同链接识别同一个平台事件，也不提供因果归因或 MMM。自由文本的事实矛盾、单位换算与真伪仍需人工核查。

多品牌是数据分区，不是多人权限系统。远程访问、身份认证、RBAC、大规模并发、系统级常驻服务与高可用需要独立设计和验证。真实发布、邮件发送、广告支出和支付执行不在当前版本范围。

新增能力优先解决数据错误与主流程阻塞。欢迎通过 [Issues](https://github.com/xliang-L/harbor/issues) 提供实际场景和可验收结果。
